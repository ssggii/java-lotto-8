# java-lotto-precourse

## 프로그램 소개

사용자에게 로또 구입 금액과 당첨 번호를 받아, 구매한 로또의 당첨 내역과 수익률을 반환하는 프로그램입니다.

## 기능 목록

### Lotto

- [x] 로또 검증
    - 로또 번호의 개수는 6개이다.
    - 로또 번호의 숫자 범위는 1~45까지이다.
    - 로또 번호는 중복되지 않는 6개의 숫자이다.
    - 예외 상황
        - [x] 로또 번호의 개수가 6개가 아니면 예외가 발생한다.
        - [x] 로또 번호의 숫자가 1~45 사이의 범위가 아니면 예외가 발생한다.
        - [x] 로또 번호가 중복되면 예외가 발생한다.

### LottoIssuer

- [ ] 로또 발급
    - 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
    - 로또 1장의 가격은 1,000원이다.
    - 예외 상황
        - 구입 금액이 음수이면 예외가 발생한다.
        - 구입 금액이 로또 가격보다 작으면 예외가 발생한다.

### LottoDrawer

- [ ] 모든 로또에 대하여 당첨 번호와 일치하는 숫자 개수 계산
- [ ] 모든 로또에 대하여 우승자 순위 결정

### ReturnRateCalculator

- [ ] 당첨금 총합 계산
- [ ] 수익률 계산

### InputView

- [ ] 구입 금액 입력 받기
- [ ] 당첨 번호 입력 받기
- [ ] 보너스 번호 입력 받기

### OutputView

- [ ] 로또 구매 개수 출력
- [ ] 로또 숫자 출력
- [ ] 당첨 통계 안내문구 출력
- [ ] 당첨 내역 출력
- [ ] 수익률 출력

### LottoMachineController

- [ ] 전체 흐름 제어
- [ ] 사용자 입력 예외 시 재입력 받기
