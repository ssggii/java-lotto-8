# java-lotto-precourse

## 프로그램 소개

사용자에게 로또 구입 금액과 당첨 번호를 받아, 구매한 로또의 당첨 내역과 수익률을 반환하는 프로그램입니다.

## 기능 목록

### Lotto

- [x] 로또 검증
    - 로또 번호의 개수는 6개이다.
    - 로또 번호의 숫자 범위는 1~45까지이다.
    - 로또 번호는 중복되지 않는 6개의 숫자이다.
    - 예외 상황
        - [x] 로또 번호의 개수가 6개가 아니면 예외가 발생한다.
        - [x] 로또 번호의 숫자가 1~45 사이의 범위가 아니면 예외가 발생한다.
        - [x] 로또 번호가 중복되면 예외가 발생한다.
- [x] 특정 번호 목록에서 일치하는 숫자의 개수 계산
    - 특정 번호 목록에서 로또 번호와 일치하는 숫자의 개수를 계산한다.
    - 특정 번호 목록의 번호들은 중복될 수 없다.

### LottoIssuer

- [x] 로또 발급
    - 로또 가격과 구입 금액을 받아서 구입 금액에 해당하는 만큼 로또를 발행한다.
    - 로또 가격이 0 이하이면, 로또 가격을 1000원으로 계산한다.
    - 예외 상황
        - [x] 구입 금액이 음수이면 예외가 발생한다.
        - [x] 구입 금액이 1000원으로 나누어 떨어지지 않으면 예외가 발생한다.

### LottoDrawer

- [x] 로또 추첨
    - 당첨 번호와 일치하는 숫자의 개수를 비교하여 당첨 순위를 결정한다.
    - 일치하는 숫자가 5개인 경우, 보너스 번호의 일치 여부를 검사한다.
    - 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
        - 1등: 6개 번호 일치 / 2,000,000,000원
        - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
        - 3등: 5개 번호 일치 / 1,500,000원
        - 4등: 4개 번호 일치 / 50,000원
        - 5등: 3개 번호 일치 / 5,000원

### ReturnRateCalculator

- [ ] 당첨금 총합 계산
- [ ] 수익률 계산

### InputView

- [x] 구입 금액 입력 받기
    - 예외 상황
        - [x] 빈 문자열이나 공백을 받으면 예외가 발생한다.
- [x] 당첨 번호 입력 받기
    - 예외 상황
        - [x] 빈 문자열이나 공백을 받으면 예외가 발생한다.
- [x] 보너스 번호 입력 받기
    - 예외 상황
        - [x] 빈 문자열이나 공백을 받으면 예외가 발생한다.

### OutputView

- [x] 에러 메시지 출력
- [x] 로또 개수 및 번호 출력
- [ ] 당첨 통계 안내문구 출력
- [ ] 당첨 내역 출력
- [ ] 수익률 출력

### LottoMachine

- [x] 구입 금액 준비하기
    - 사용자로부터 구입 금액을 입력받는다. 예외가 발생한 경우 다시 입력받는다.
- [x] 로또 발급 및 번호 출력
    - 구매한 로또 개수와 번호를 출력한다.
- [x] 당첨 번호 준비하기
    - 사용자로부터 당첨 번호를 입력받는다. 예외가 발생한 경우 다시 입력받는다.
- [x] 보너스 번호 준비하기
    - 사용자로부터 보너스 번호를 입력받는다. 예외가 발생한 경우 다시 입력받는다.
- [ ] 추첨 진행 및 결과 출력
    - 추첨을 진행하고 구매한 로또의 당첨 결과를 보여준다.

### UserInputParser

- [x] 문자열에서 구입 금액 파싱
    - [x] 정수 형태가 아닌 문자열을 파싱하는 경우 예외가 발생한다.
    - [x] 구입 금액이 음수인 경우 예외가 발생한다.
    - [x] 구입 금액이 1000원으로 나누어 떨어지지 않으면 예외가 발생한다.
- [x] 문자열에서 당첨 번호 파싱
    - 구분자는 쉼표(,)만 허용한다.
    - 당첨 번호는 중복되지 않는 6개의 숫자이다.
    - 각각의 숫자는 1 ~ 45 사이의 숫자이다.
    - 예외 상황
        - [x] 당첨 번호의 개수가 6개가 아니면 예외가 발생한다.
        - [x] 당첨 번호의 숫자가 정수 형태가 아니면 예외가 발생한다.
        - [x] 당첨 번호의 숫자가 음수이면 예외가 발생한다.
        - [x] 당첨 번호의 숫자가 1~45 사이의 범위가 아니면 예외가 발생한다.
        - [x] 당첨 번호가 중복되면 예외가 발생한다.
- [x] 문자열에서 보너스 번호 파싱
    - 보너스 번호는 1개이며, 1에서 45 사이의 숫자이다.
    - 보너스 번호는 6개의 당첨 번호와 중복될 수 없다.
    - 예외 상황
        - [x] 보너스 번호가 음수이면 예외가 발생한다.
        - [x] 보너스 번호가 1~45 사이의 범위가 아니면 예외가 발생한다.
        - [x] 보너스 번호가 당첨 번호의 숫자와 중복되면 예외가 발생한다.
